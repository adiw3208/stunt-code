<h1 align="center" style="background: #fff;color: black;border-radius: 10px;padding: 32px 0px;font-weight: 900;font-family: sans-serif;">STUNT-CODE Documentation</h1>

<div align="center">
<span style="font-weight: 900;color:cyan;"> STUNT CODE</span> 🚀 is a <b>VS Code Extension</b> that automates the creation of structured project folders and files. Instead of manually setting up your project, you can generate everything instantly with a single command.
</div>

### ✅ Available Project Structures:

- **Beginner Project** `(HTML, CSS, JS)`
- **Standard Web Structure** `(Assets, Public, Src, etc.)`
- **NextJs `(JavaScript & TypeScript)`**
- **Vite + React `(JavaScript & TypeScript)`**
- **Vite + Svelte `(JavaScript & TypeScript)`**
- **Vite + Vue `(JavaScript & TypeScript)`**

## ✅ Requirements

Before using Stunt-Code, ensure you have:

- **VS Code** version **1.98.0** or later
- **Node.js** installed (for Vite projects)
- **NPM or Yarn** for package management

## ⚙️ Extension Settings

This extension does not require additional settings. Simply open the **Command Palette** (`Ctrl + Shift + P`) and search for:

- `Stunt-Code: Beginner`
- `Stunt-Code: Standard`
- `Stunt-Code: NextJs-JS`
- `Stunt-Code: NextJs-TS`
- `Stunt-Code: Vite React-JS`
- `Stunt-Code: Vite React-TS`
- `Stunt-Code: Vite Svelte-JS`
- `Stunt-Code: Vite Svelte-TS`
- `Stunt-Code: Vite Vue-JS`
- `Stunt-Code: Vite Vue-TS`

# Change Log

All notable changes to the "stunt-code" extension will be documented in this file.

Check [Keep a Changelog](http://keepachangelog.com/) for recommendations on how to structure this file.

## [1.4.0] - 2026-05-19

### New Auto-Generate Features

#### Component Generator
- **Generate Component** - Create React/Vue/Svelte/Vanilla JS components with styles
  - Auto-detects project type (React, Vue, Svelte, Next.js)
  - PascalCase validation for component names
  - Generates component file + CSS file
  - Supports JSX, Vue SFC, Svelte, and vanilla JS class components

- **Generate Page** - Create new pages with framework-specific templates
  - Auto-detects project structure
  - Generates page template with proper routing setup
  - Supports all major frameworks

- **Generate API Route** - Create API endpoints
  - Next.js: App Router API routes (route.js)
  - Generic: Express-style route handlers
  - Includes GET and POST method templates

#### Post-Setup Automation
- **Auto Install Dependencies** - Optional `npm install` after project creation
  - Progress notification during installation
  - Error handling with user feedback

- **Git Auto-Init** - Initialize repository with first commit
  - `git init` + `git add .` + initial commit
  - Commit message: "Initial commit - Generated by Stunt Code"

- **Environment Setup** - Generate configuration files
  - `.env` and `.env.example` with framework-specific variables
  - `.eslintrc.json` with recommended rules
  - `.prettierrc` with standard formatting
  - `.editorconfig` for editor consistency
  - Framework-specific configs (Next.js, Vite)

- **Docker Support** - Production-ready containerization
  - Multi-stage `Dockerfile` optimized for each framework
  - `docker-compose.yml` with app, database (PostgreSQL), and Redis
  - `.dockerignore` for clean builds
  - Nginx configuration for Vite projects

- **Quick Start** - Post-project setup wizard
  - Start dev server in integrated terminal
  - Open README documentation
  - Open in browser
  - Install dependencies on demand

### Improvements
- Enhanced `cliHelper.js` with sequential command execution
- Added `envGenerator.js` utility for environment configuration
- Added `dockerGenerator.js` utility for containerization
- Added `quickStart.js` utility for developer workflow
- Improved error handling across all utilities
